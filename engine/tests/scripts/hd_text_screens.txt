# hd_pack and hd_text=1; with hd=0 the fbshots are the plain 640x480 frames
# the tests compare against). Each screen is captured as the presented
# framebuffer (fbshot) and as the 8-bit window composition (legacyshot), which HD
# text must leave exactly as without it.

wait 1500

key e
