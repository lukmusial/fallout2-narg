## Installation on Windows

1. Optional: install the [Restoration Project](rpu.md) first (its installer).
1. Extract `narg_v*_windows.zip` into the game folder (e.g. `C:\GOG Games\Fallout 2`).
1. Run `narg-install.bat`. It installs `fallout2-ce.exe` and `ce.dat` (backing up any existing ones to `backup\narg\`), sets up `fallout2.cfg` for HD (screen size of the primary display), and installs `f2_res.dat` when the game has none. Options (README): `narg-install.bat -With no_wind`.
1. Start `fallout2-ce.exe`. The original `fallout2.exe` (and RPU's sfall `ddraw.dll`) stay; they are not used by Narg Edition.
